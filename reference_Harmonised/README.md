## Reference information from the CMIP7 Harmonised Data Request

The files in these folders describe Opportunities, Variable Groups and Experiment Groups from the Harmonised Data Request.

They are provided for reference only (not for editing information in the Harmonised DR).
Requestors may find them useful, e.g. to copy a similar variable group and edit it to create an new variable group in the Unharmonised DR.

Harmonised DR content can also be viewed in these ways:
- [Airtable](https://bit.ly/CMIP7-DReq-latest)
- [DR web viewer](https://cmip-data-request.github.io/cmip7-dreq-webview/latest)


### How to generate these files

They are generated by a command-line utility in the [DR software](https://github.com/CMIP-Data-Request/CMIP7_DReq_Software):
```bash
get_harmonised_DR_as_yaml_files v1.2.2.5 -a
```
will create a directory `reference_Harmonised` in the current directory with subdirectories containing the yaml files.

The Harmonised Data Request version used to create the files (`v1.2.2.5` in the above example) is logged in each file.
